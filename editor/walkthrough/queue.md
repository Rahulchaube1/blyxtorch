# Train the print-queue model

Open the extracted project workspace. The **Evaluate print queue** task fits a two-input classifier on 16 synthetic jobs and scores six separate jobs. It prints a row count of 6 and a mean loss near 0.00234. **Predict new print jobs** trains with the same seed and prints four probabilities. Edit the CSV files to try your own normalized inputs.

Native tasks use the bundled trainer on Windows x64, Linux x64 or Apple Silicon macOS.
